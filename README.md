# News in One Image — 17 November 2026

One image summing up the world's news of Tuesday 17 November 2026, built
for make.fun's "Sum up 17 November's world news in one image" bounty
($250 in USDC).

The image is a newspaper-style front page: Asia summit talks (Trump
travels to Asia for APEC in Shenzhen and the planned trilateral talks
with Xi Jinping and Vladimir Putin), the Kerch Bridge hit (a Ukrainian
strike damaged the bridge, Russia struck Kyiv bridges), Japan scrambling
fighter jets after Russian aircraft violated its airspace, and Estonia
closing its border crossings with Russia from 1 December over a foiled
sabotage plot.

## Run

The program writes the image deterministically, with no network:

```
python3 main.py
```

It copies the bundled image to `/output/entry.png` — running it twice
writes the same bytes. The image is a 1024x1024 PNG under 1 MiB.
